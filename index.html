What's built today

Two skills, chained together — the core of Phase 1.

monday-reader

skills/monday-reader/SKILL.md
  • Reads a monday.com campaign item via the monday MCP (columns + updates)
  • Resolves the item's Figma design link, preferring structured columns over freeform update text
  • Resolves the item's source-of-truth CTA link the same way
  • Hands both off to figma-to-html instead of guessing when either is missing

figma-to-html

skills/figma-to-html/SKILL.md
  • Reads a Figma email design via the Figma MCP and walks it section by section
  • Maps each section onto monday.com's approved email component library — headings, body text, buttons, images, columns, lists, footer
  • Applies the required Braze substitutions: first-name personalization, tracked monday.com links, magic-link content blocks, footer content block
  • Cross-checks the assembled CTA link against monday-reader's source-of-truth link
  • Validates the resulting HTML and loops to fix issues before handoff

Verified end-to-end against a real campaign item — the test output confirms the HTML's CTA link matches the monday item's stored CTA link exactly.
